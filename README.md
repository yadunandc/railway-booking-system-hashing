# Railway Booking System Using Hashing

## Description
This project implements a railway booking system using hashing in C. It demonstrates three collision-resolution techniques: Linear Probing, Quadratic Probing and Double Hashing.

## Features
- Inserts railway booking IDs into a hash table.
- Implements three collision-resolution techniques.
- Searches for existing and non-existing booking IDs.
- Counts the number of probes required.
- Calculates the load factor.

## Technologies Used
- C Programming
- Data Structures
- Hashing

## Booking IDs
23, 43, 13, 33, 53, 63, 73

## How to Run
Compile: `gcc main.c -o railway`

Run: `./railway`
